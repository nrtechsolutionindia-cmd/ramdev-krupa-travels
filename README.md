# Ramdev Krupa Travels — Next.js Website

A responsive custom-coded website built with Next.js 16, React, TypeScript and Tailwind CSS 4.

## Run locally
1. Install Node.js 20.9 or later.
2. Open this folder in VS Code / terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Build
`npm run build`

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. Import the repository in Vercel.
3. Keep the framework preset as Next.js.
4. Deploy.

## Booking form

## Before publishing
- Confirm the actual vehicle photos and replace the sample image URLs in `app/page.tsx` and `app/globals.css`.
- Confirm service locations, phone number, vehicle seat configurations and operating terms.
- Add a privacy policy and business address if required.
